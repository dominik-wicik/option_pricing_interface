The option pricing interface is simple calculator based on the Black-Scholes-Merton model. It takes 6 inputs related to a given option and returns premiums and greek values of that option. All of the variables are explained in the "Formulas & Variables" section. 

The script "option_pricing_interface" requires python as well as three python libraries: streamlit, numpy and scipy.

After you have installed python, you can install the libraries through the following command in the terminal: "python -m pip install (library name)".

In order to run the script through streamlit (localhost), run in the terminal: "python -m streamlit run option_pricing_interface.py".

You should be automatically redirected to the web browser, where the webapp will be locally hosted.

It is strictly recommended that you turn on dark mode in the top right corner, as some elements may not functions properly on light mode.
